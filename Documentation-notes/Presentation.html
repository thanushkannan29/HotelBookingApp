What is Thanush StayHub?

An end-to-end hotel booking ecosystem built for three distinct user roles with real-world business logic.

🎯 Problem Solved
Hotels need a unified platform to manage rooms, pricing, reservations, and guest interactions — while guests need a seamless booking experience with transparent pricing and instant confirmations.
💡 Solution
A role-based SPA with real-time inventory, dynamic date-range pricing, wallet-based refunds, promo codes, automated no-show handling, and a 2% platform commission model.

Core Feature
Core Feature
Booking Flow

From hotel discovery to confirmed reservation — fully automated end-to-end.

1
Search Hotels
Filter by city, dates, guests. Real-time availability check against RoomTypeInventory.
2
Select Room Type
Dynamic pricing from RoomTypeRate date ranges. GST calculated per hotel setting.
3
Apply Promo / Wallet
Optional promo code discount + wallet balance deduction at checkout.
4
Payment
Simulated UPI / Card / NetBanking. Transaction recorded with PaymentStatus.
5
Reservation Confirmed
ReservationCode generated. Inventory decremented. QR code issued.
6
Check-In
Admin marks IsCheckedIn. Room assigned via ReservationRoom join table.
7
Check-Out & Review
Status → Completed. Guest can submit one review per reservation.
8
Cancellation
Optional 10% protection fee. Refund to wallet. Inventory restored automatically.
